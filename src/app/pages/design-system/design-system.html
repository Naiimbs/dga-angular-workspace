Getting Started

Install, import, and use DGA Angular components in your project.

Installation

The DGA Angular library is distributed as @dev-dga/angular. Install it alongside the CSS package:

npm install @dev-dga/angular @dev-dga/css

Load Styles

Import the DGA token layer and component styles in your root SCSS or angular.json styles array. The tokens layer must come first:

// styles.scss
@use '@dev-dga/css/dist/variables.css';
@use '@dev-dga/css/dist/index.css';

Import Components

All components are standalone. Import only what you need:

import {  DgaButtonComponent,
  DgaCheckbox,
  DgaRadioGroup,
  DgaTabs,
  DgaDigitalStamp,} from '@dev-dga/angular';

@Component({  imports: [DgaButtonComponent, DgaCheckbox, DgaRadioGroup, DgaTabs],
  // ...})

Register Icons

Inject DgaIconRegistry at application root to enable icon rendering across all <dga-icon> components:

import { DgaIconRegistry } from '@dev-dga/angular';

// In your root component or app.config.ts providers:
private iconRegistry = inject(DgaIconRegistry);

Accessibility

DGA components are designed for keyboard and assistive-technology use from the ground up.

Keyboard Navigation

TabMove focus between interactive controls
Space / EnterActivate buttons, checkboxes, switches
Arrow KeysNavigate tabs (Left/Right), radio groups (Up/Down/Left/Right), dropdowns
Home / EndJump to first/last tab or dropdown item
EscapeClose dropdowns, modals, and slideout menus

ARIA Attributes

Components emit the correct ARIA roles and properties automatically:

  • aria-selected on tab triggers, role="tablist" on list
  • aria-invalid on inputs and checkboxes with error state
  • aria-readonly for read-only form controls
  • aria-expanded on accordion, digital stamp, and dropdown triggers
  • aria-required on required form fields
  • aria-disabled on disabled tab triggers

Focus Management

All interactive elements use :focus-visible with a high-contrast ring. Focus is trapped inside modals and returned to the trigger on close. Radio groups implement roving tabindex per ARIA patterns.

RTL Support

All components use CSS logical properties (inline-start, block-start, etc.). Add dir="rtl" to any ancestor element and the layout mirrors automatically — including arrow-key navigation in tabs and breadcrumbs.

<section dir="rtl" lang="ar">
  <dga-tabs [tabs]="tabItems" />
</section>

Theming & Tokens

DGA tokens flow from design primitives down to component styles. No component uses hardcoded colors.

Token Architecture

Tokens are defined as CSS custom properties on :root and split into layers:

  • Primitive palettes — --ddga-sa-*, --ddga-gray-*, --ddga-gold-*, --ddga-error-*, etc.
  • Semantic tokens — --ddga-color-primary, --ddga-color-error, --ddga-text-primary, etc.
  • Component tokens — --ddga-tabs-indicator-thickness, --dga-icon-size, etc.

Dark Mode

Add data-theme="dark" to any ancestor element to enable dark mode. Components detect this via attribute selectors and adjust colors using the same token layer:

<body data-theme="dark">
  <dga-checkbox [checked]="true">Dark mode checkbox</dga-checkbox>
</body>

Gold & Semantic Tokens

The Gold palette (--ddga-gold-*) is available for featured content. Use semantic tokens where possible — they respond to theme changes automatically:

/* Preferred — responds to theme */
color: var(--ddga-color-primary);
background: var(--ddga-color-muted);

/* Gold for featured UI only */
background: var(--ddga-gold-50);
color: var(--ddga-gold-800);

Migration from React

Components share the same CSS class names and token layer as the React DGA library. CSS loaded from @dev-dga/css works in both. Angular component templates differ but emit the same .ddga-* classes to maintain style compatibility.
