@dev-dga/angular

The official DGA Angular Design System library — React parity, accessible, RTL-ready.

Introduction

The @dev-dga/angular library provides a comprehensive suite of UI components, forms, and icons aligned with the DGA Design System specifications. Every component mirrors the behavior of the React source of truth (@dev-dga/react v1.3.1) while providing an idiomatic Angular API.

Installation

npm install @dev-dga/angular

Setup — Importing Styles

Import the DGA design tokens in your application's global styles.scss:

@use '@dev-dga/angular/styles';

This provides all CSS custom properties (--ddga-*) required by every component. Access tokens in your components using standard CSS syntax:

.example-card {{ '{' }}
  color: var(--ddga-color-primary);
  background-color: var(--ddga-color-background);
  border: 1px solid var(--ddga-color-border);
{{ '}' }}

Importing Components

All components are standalone. Import only what you need:

import {{ '{' }} DgaButton, DgaInput, DgaIcon {{ '}' }} from '@dev-dga/angular';

@Component({{
  '{' }} standalone: true,
  imports: [DgaButton, DgaInput, DgaIcon],
  template: `<dga-button variant="primary">Save</dga-button>`
{{ '}' }})

Buttons

<dga-button variant="primary">Submit</dga-button>
<dga-button variant="secondary">Cancel</dga-button>
<dga-button variant="ghost" [disabled]="true">Disabled</dga-button>

Form Controls

All form controls implement ControlValueAccessor and work with both Reactive Forms and Template-Driven Forms.

<dga-input label="Email" [(ngModel)]="email" />
<dga-checkbox [(ngModel)]="accepted">Accept terms</dga-checkbox>
<dga-switch [(ngModel)]="notifications">Notifications</dga-switch>
<dga-slider label="Volume" [(ngModel)]="volume" [showValue]="true" />

Icons

Icons use the centralized DgaIconRegistry. Register SVG or font icons before use:

import {{ '{' }} DgaIconRegistry {{ '}' }} from '@dev-dga/angular';

constructor(registry: DgaIconRegistry) {{ '{' }}
  registry.registerIcon({{ '{' }}
    name: 'check',
    type: 'svg',
    viewBox: '0 0 24 24',
    svgHtml: '<path d="M20 6 9 17l-5-5" fill="none" stroke="currentColor" stroke-width="2" />'
  {{ '}' }});
{{ '}' }}
<dga-icon name="dga-icon-add-01" variant="stroke-rounded"></dga-icon>

RTL Support

All components use CSS logical properties. Enable RTL by setting dir="rtl" on the root element or a parent container.

Accessibility

Every component ships with correct ARIA roles, states, and keyboard navigation aligned with WCAG 2.1 AA standards.

MODHS Integration

MODHS can consume this library directly:

  1. Install: npm install @dev-dga/angular
  2. Import styles in styles.scss
  3. Import standalone components per feature module
  4. Use DgaIconRegistry to register the icons needed
